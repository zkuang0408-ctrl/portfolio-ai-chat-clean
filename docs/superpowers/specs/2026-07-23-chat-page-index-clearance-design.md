# 首页对话区与页码避让设计

## 目标

桌面端首页的 AI 对话区不得与左下角页码标识重叠。回答、输入框、发送按钮和状态提示作为一个整体上移，保留至少约 24px 的视觉安全距离。

## 方案

- 保留对话区现有的左侧位置、宽度、透明样式与内容结构。
- 将桌面端 `.hero-chat` 的下边界从 `24–34px` 提高到 `96–112px`。
- 同步收紧桌面端最大高度；长回答继续在现有滚动区域内部滚动。
- `760px` 以下仍使用正常文档流，移动端布局不做改变。
- 不隐藏、不移动左下角页码标识。

## 验证

- 样式回归测试应确认桌面端对话区采用新的下边界和对应最大高度。
- 移动端回归测试继续确认 `bottom: auto` 与 `max-height: none`。
- 完整测试、生产构建通过后生成新的 Vercel Preview 供浏览器检查。
