# 移动端问答框键盘贴边与圆角修复设计

## 目标

修复移动端展开 AI 问答框时的两个视觉问题：底部圆角消失，以及输入法键盘弹出后问答框与键盘之间出现明显断层。

## 已确认方案

采用方案 A：

- 仅在移动端键盘激活时，让展开问答框的底边贴合浏览器可用视口的最低边界，不再额外保留 `76px` 保底距离或 `12px` 悬空间隔。
- 问答框四角统一使用 `24px` 圆角，使底部圆角与顶部圆角大小一致。
- 键盘未激活时继续保留现有安全边距，避免问答框贴住物理屏幕底边和系统手势区。
- 保留现有 Visual Viewport 连续跟随与防闪烁机制，不重新引入基于键盘高度阈值的布局切换。

## 实现边界

- 只修改移动端（`max-width: 760px`）问答框样式和对应测试。
- 键盘激活态使用现有 `data-chat-keyboard="active"` 状态覆盖展开面板的底部定位。
- 展开、收起、拖拽、发送、加载和滚动逻辑保持不变。
- 不修改桌面端、首页内容、作品、简历、粒子人像、AI 后端或 Production 部署。

## 验收标准

1. 手机键盘打开后，问答框底边与可用视口底边贴合，不出现可见页面内容断层。
2. 展开问答框的四个圆角均为 `24px`。
3. 键盘升降期间面板位置继续单调、平滑变化，不在激活阈值附近跳动或闪烁。
4. 键盘关闭后恢复既有底部安全距离。
5. 320px、390px、430px 及横屏移动视口无横向溢出；桌面样式不变。

## 验证

- 先添加失败的 CSS 契约与 Playwright 布局断言，再实现最小样式覆盖。
- 运行相关 Vitest、移动端 Playwright、完整 Vitest 和生产构建。
- 在本地 Preview 检查键盘开合前后的面板底边与四角；验收前只部署 Cloudflare Preview，不切换 Production。
